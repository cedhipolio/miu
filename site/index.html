What it does

Redline tools that know the form

Click a cell to drop editable red text on it. Strike a row that was removed, strike a value and write the as-built one above it, cross out a figure. The marks line up with the printed table because they are measured against it.

Drawing tools that behave

Lines, arrows, dimensions, polylines, boxes, circles, clouds and callouts — each with its own colour, weight, ending, corner style and pattern, set on the tool rather than hunted for in a panel. Draw by dragging, or click once to start and once to finish.

An export that stays editable

The pages come out exactly as they went in — vector, selectable, searchable. Each mark is written as a PDF annotation, so whoever opens it next can move a note or correct a value without the page turning into a picture of itself.

Assist

Read a loading or equipment table off the sheet and edit it as a form, writing back only what changed. Import an as-built and get a proposed redline wherever the document disagrees. Keep a library of the markups and stamps you place on every job.

Nothing is uploaded

There is no server. The tool is one HTML file: the PDF engine, the writer and the fonts are all inside it, and the document you open is read in the tab and never sent anywhere. Saved redlines live in that browser's own storage, on that machine. It works with the network unplugged — which is also what makes it safe to point at a client's drawings.

Getting started

1 · Open a PDF

Drop a file anywhere on the page, or use Open PDF. The site name is read off the first page and becomes the export's file name.

2 · Mark it up

Pick a tool with its letter key. Escape drops the selection; Escape again puts the tool down. Ctrl+S saves to the browser so a refresh costs nothing.

3 · Export

Ctrl+E writes the marked-up PDF. Copy list gives you the corrections as text for an email or a tracker.
